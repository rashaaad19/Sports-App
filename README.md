# Sports App (Flutter and Firebase)

> **Training project.** This repository was built as part of the *Frontend and Mobile Cross-Platform Training* at the **Information Technology Institute (ITI), Port Said** (03/2025 – 08/2025). It is a learning exercise from the program, not a production application.

A sports app built with **Flutter** and **Dart**, using **Firebase**, running on Android and iOS from a single codebase.

## Getting Started

**Prerequisites:** [Flutter SDK](https://docs.flutter.dev/get-started/install) and an emulator or a connected device.

```bash
git clone https://github.com/rashaaad19/Sports-App.git
cd Sports-App
flutter pub get
flutter run
```

> The app needs your own Firebase project configuration. See the [FlutterFire setup guide](https://firebase.flutter.dev/docs/overview).
